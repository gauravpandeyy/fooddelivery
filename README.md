# 🍔 MuchMate

**MuchMate** is a modern, responsive food delivery web application built using **ReactJS**, **Tailwind CSS**, and **Redux**. It allows users to browse local restaurants, add meals to their cart, and place orders seamlessly.

## 🚀 Features

- 🛍️ Browse a list of restaurants and food items
- 🔍 Filter and search for meals
- 🛒 Add/remove items from the shopping cart
- 💳 Checkout with a responsive order summary
- ⚛️ State management using Redux
- 💡 Styled with Tailwind CSS for modern UI/UX
- 📱 Fully responsive and mobile-friendly

## 🛠️ Tech Stack

- **Frontend**: [ReactJS](https://reactjs.org/)
- **State Management**: [Redux](https://redux.js.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
